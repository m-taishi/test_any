# ODMパイプライン解析による汎用データマート候補抽出 — 資料一式

ODMの約20,000件のXMLデータパイプラインを解析し、汎用データマート候補を抽出する取り組みについて、
**汎用化の考え方**と**分析手法**を視覚的に説明するための資料。同じ内容を2つの形式で用意している。

| ファイル | 形式 | 用途 |
|---|---|---|
| `index.html` | スライド（全26枚） | 会議・説明会でページを送りながら話す |
| `overview.html` | 1枚もの（全体像） | 一画面で全体を俯瞰する・議論しながら指し示す |
| `ODM汎用データマート候補抽出_プレゼン資料.pdf` | PDF 26ページ | 配布・印刷（`index.html` から生成） |
| `ODM汎用データマート候補抽出_全体像1枚版.pdf` | PDF 1ページ | 配布・A3等での印刷（`overview.html` から生成） |

いずれも外部依存なし・単一ファイル・オフラインで動作する。ブラウザで開くだけで使える。

## 2. `overview.html` — 1枚もの（全体像）

スライドを送らずに全体を一画面で見せるための版。1600×1100 のポスターを画面サイズに合わせて縮小表示する。

| 操作 | 方法 |
|---|---|
| 表示モード切替 | `F` / 右上ボタン（**画面に合わせる** ⇄ **原寸で見る**） |

既定は「画面に合わせる」（スクロールなしで全体が入る）。細部を読むときは「原寸で見る」に切り替えると
1600px幅の原寸でスクロール表示になる。1920×1080 のディスプレイなら既定モードでそのまま読める密度にしてある。

盛り込んでいる内容は、現状／目指す姿の対比、分析の流れ（STAGE 1–6）、第N連結の定義、維持率による汎用化境界、
判断シグナル8項目、Connected Table Set と Fingerprint の役割分担、LLMの適用範囲、実装フェーズとガードレール、注意事項。

## 3. PDFの再生成

HTMLを更新したらPDFも作り直す。どちらも `@media print` を持っているので、ブラウザの印刷（`Ctrl+P` →
「PDFに保存」、背景のグラフィックを有効）でも同じ結果になる。コマンドで作る場合は次のとおり。

```bash
chrome --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf="ODM汎用データマート候補抽出_プレゼン資料.pdf" "file:///<path>/index.html"
```

```bash
chrome --headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf="ODM汎用データマート候補抽出_全体像1枚版.pdf" "file:///<path>/overview.html"
```

スライド版は1280×720（16:9）で26ページ、1枚版は1600×1100で1ページになる。
ページ数が増える場合は `overview.html` の `@page{size:...}` の高さを内容に合わせて広げる。

## 編集

どちらも単一のHTMLファイルで、配色は先頭の `:root` のCSS変数で一括変更できる。
`index.html` は `<section class="slide" data-title="..." data-chap="...">` を追加するだけでスライドを増やせる
（`data-chap` を付けたスライドが目次で章の先頭になる）。
`overview.html` はパネルを増減したら縦が伸びるため、印刷用の `@page` の高さもあわせて調整する。
