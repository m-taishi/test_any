# ODMパイプライン解析による汎用データマート候補抽出 — プレゼン資料

ODMの約20,000件のXMLデータパイプラインを解析し、汎用データマート候補を抽出する取り組みについて、
**汎用化の考え方**と**分析手法**を視覚的に説明するためのHTMLプレゼンテーション。

## 使い方

`index.html` をブラウザで開くだけ。外部依存なし・単一ファイル・オフラインで動作する。

| 操作 | キー |
|---|---|
| 次のスライド | `→` / `Space` / `PageDown` / 画面右側クリック |
| 前のスライド | `←` / `PageUp` / `Backspace` / 画面左側クリック |
| 先頭 / 末尾 | `Home` / `End` |
| 目次の開閉 | `M` / 右上「目次」ボタン / `Esc` で閉じる |

スライドは 1280×720 のステージを画面サイズに合わせて自動スケールする。
プロジェクタや会議室ディスプレイでは、ブラウザを全画面（`F11`）にして使う。
URLの `#s13` のようなハッシュで特定スライドから開始できる。

## 編集

単一のHTMLファイル。スライドは `<section class="slide" data-title="..." data-chap="...">` を追加するだけで増やせる
（`data-chap` を付けたスライドが目次で章の先頭になる）。配色は先頭の `:root` のCSS変数で一括変更できる。
